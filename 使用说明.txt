浮光播放器 1.0.1 — Apple Music for Windows 桌面悬浮控制器

使用
双击 FloatingMusic.exe，保持 Apple Music 在后台运行。无需打开官方迷你播放器。
顶部拖动移动；图钉切换置顶；“词”显示或隐藏歌词；齿轮设置背景透明度。
待播列表和歌词候选窗口沿用主窗口样式、透明度与置顶设置。

播放与待播列表
• 显示歌曲、封面、进度；支持播放 / 暂停、上一首、下一首。
• 进度通过 UI Automation 的 LCDScrubber 控件调整，并核验实际位置。已在 Apple Music 1.1540.23042.0 窗口最小化时验证跳转。
• 音量通过 Windows Core Audio 调整 AppleMusic 与同一安装目录下 AMPLibraryAgent 会话，不改变其他应用音量。
• “待播列表”读取官方控件当前提供的歌曲。点击一首歌后，通过系统媒体接口按队列顺序逐首跳转并核对；靠后的歌曲需要更久，可能短暂经过前面的歌曲。若队列变化、实际播放顺序不符或请求失败，会停止，可能停留在已经跳到的中间歌曲。
• 喜爱 / 取消和减少推荐按钮通过官方歌曲操作菜单提交；喜爱状态在点击后核对。
程序不会设置官方窗口置顶、激活或还原，不采用坐标定位或键鼠模拟。

歌词匹配与候选
• 默认显示简体。歌词栏“简 / 原”切换显示方式；原文和时间轴保持不变。
• 自动匹配统一简繁体、标点和大小写，识别中英文并列歌手名，并核对歌名、时长、专辑和现场版本。同步歌词优先于纯文本。
• 多个可靠候选的歌词内容不同时，不猜测版本，提示用户选择。不同专辑、时长偏差或歌手差异会在候选中标明。
• 点击“搜 / 选”查看候选。每项显示歌名、歌手、专辑、时长及同步 / 纯文本状态；点击一项使用，仅当前这次播放生效，不保存到本地。
• 切歌后不记住手动选择；再次播放可重新选择。自动查询、候选和手动选择的在线歌词只在内存中使用。
• 支持导入 LRC / TXT，支持 UTF-8、带 BOM 的 Unicode、GB18030。导入歌词是用户主动指定的本地文件，与在线候选分开。
• 歌词校时范围 ±30 秒，每次 0.5 秒；切歌重置校时。
纯文本没有时间轴，不会假装逐行同步。选择其他录音版本仍可能有时间差。

联网与存储
全部在线歌词、候选仍来自 LRCLIB（https://lrclib.net），发送歌名、歌手进行检索。专辑和时长用于本地匹配核对。不接入其他歌词平台，不使用小模型。
自动联网默认开启，可在设置中关闭。无需 Apple 密码或账户令牌，不上传本地歌词。
preferences.ini 保存外观、简体开关和联网设置。
lyrics 文件夹仅保存用户主动导入的歌词。在线歌词及候选只在内存缓存，退出后清空，不保存在线歌词文件或选择记录。
seek-status.txt 保存最近一次跳转结果。src 是源代码。

兼容性
Windows 10 1809 或更新，64 位，.NET Framework 4.8。无需管理员权限或开机启动项。
官方客户端更新可能改变辅助功能控件。无可用控件或请求失败时会提示，不会自动弹出官方窗口。
运行 src/build.ps1 可编译；缺少 Windows SDK 元数据时会从微软 NuGet 下载对应 Contracts 包。
